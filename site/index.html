One module, a whole dashboard

AtriumUI ships as a single tree-shaken ES module (atrium-ui.js). Use custom:au-shell-grid as a Panel view: classic drag/resize grid, or Apple Home → Rooms when floors is set. Requires Home Assistant 2024.1+.

  1. HACS → Custom repositories
  2. URL https://github.com/AlexNechayev/AtriumUI
  3. Type Dashboard, then install AtriumUI
