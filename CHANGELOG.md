# Changelog

All notable changes to AtriumUI are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.5.4] - 2026-08-25

First public GitHub / HACS release of AtriumUI.

### Added

- Single Lovelace module `atrium-ui.js` with a shared Home look and visual editors
- `custom:au-shell-grid` — classic drag/resize card grid and Apple Home → Rooms (`floors`)
- Domain cards: action, sensor, light, climate, fan, cover, switch, vacuum, device, room, calendar
- Localization for English, Russian, and Hebrew (RTL)
- HACS Dashboard distribution via GitHub Releases
- Open-source project files: license, contributing guide, code of conduct, security policy, and issue templates

### Changed

- Public repository renamed from HAD to **AtriumUI**
